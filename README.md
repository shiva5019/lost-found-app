# Lost & Found Web Application

A full-stack web application designed to help users report and recover lost and found items efficiently.  
The platform allows users to post item details, browse listings, and contact item owners.

---

## 🚀 Features
- Report lost or found items with details
- Browse items by category and status
- User authentication using Firebase
- Responsive UI for desktop and mobile
- Admin moderation for managing posts

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML, CSS, JavaScript
- Firebase Authentication

### Backend
- Node.js
- Express.js

### Database & Services
- Firebase
- Cloudinary (for image uploads)

---
